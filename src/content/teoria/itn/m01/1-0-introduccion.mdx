Hoy casi todo pasa por una red: la clase en línea, el pago con el celular, la videollamada con la familia o el
sistema de turnos de un hospital. Este módulo te da el mapa general: qué piezas forman una red, cómo se dibuja, qué
tipos existen, cómo se llega a Internet y qué hace que una red sea confiable y segura.

## 1.0.1 ¿Por qué estudiar este módulo?

Porque todo lo que verás después (cables, direcciones IP, switches, routers) encaja en este mapa. Si entiendes el
panorama, cada tema nuevo tiene un lugar donde ubicarse.

## 1.0.2 Qué vas a aprender

| Tema | Objetivo |
|---|---|
| 1.1 Las redes afectan nuestras vidas | Explicar cómo las redes influyen en la vida cotidiana |
| 1.2 Componentes de la red | Explicar cómo se usan los dispositivos host e intermediarios |
| 1.3 Topologías y representaciones | Explicar cómo se representan las redes en diagramas |
| 1.4 Tipos comunes de redes | Comparar las características de los tipos de red más comunes |
| 1.5 Conexiones a Internet | Explicar cómo se conectan a Internet las LAN y las WAN |
| 1.6 Redes confiables | Describir los cuatro requisitos de una red confiable |
| 1.7 Tendencias de red | Explicar cómo BYOD, la colaboración en línea, el video y la nube cambian la forma de usar la red |
| 1.8 Seguridad de la red | Identificar amenazas y soluciones de seguridad básicas |
| 1.9 El profesional de TI | Explicar las oportunidades laborales en redes |

los paquetes paso a paso.
