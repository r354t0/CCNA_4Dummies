## 1.2.1 Funciones de host

Un **host** es cualquier dispositivo final que participa directamente en la comunicación. Cada host se identifica en
la red por una **dirección**: cuando envía un mensaje, usa la dirección del destino para indicar a quién va.

Según lo que hace, un host puede ser:

- **Cliente**: pide información o servicios. Tu navegador es un cliente cuando abre una página.
- **Servidor**: tiene un software que entrega información o servicios a los clientes.

| Tipo de servidor | Qué ofrece | Cliente típico |
|---|---|---|
| Correo electrónico | Recibe, guarda y entrega mensajes | Outlook, la app de correo del celular |
| Web | Páginas web | Navegador |
| Archivos | Carpetas y archivos compartidos | Explorador de archivos |

Un mismo equipo puede correr varios programas de servidor a la vez, y también ser cliente de otros servicios.

## 1.2.2 Redes entre pares (peer-to-peer)

En redes muy pequeñas, como una casa, un mismo equipo puede ser cliente y servidor al mismo tiempo: comparte una
impresora con los demás mientras navega por Internet. A eso se le llama **red entre pares** o **P2P**.

| Ventajas | Desventajas |
|---|---|
| Fácil de configurar | Sin administración centralizada |
| Poco compleja | Poco segura |
| Barata: no necesita servidores ni equipos de red dedicados | No escala: con muchos equipos se vuelve un caos |
| Sirve para tareas simples como compartir una impresora | Todos los equipos actúan como cliente y servidor, lo que puede volverlos lentos |

## 1.2.3 Dispositivos finales

Son la interfaz entre las personas y la red. El mensaje **se origina** en un dispositivo final, viaja por la red y
**llega** a otro dispositivo final.

## 1.2.4 Dispositivos intermediarios

Conectan los dispositivos finales a la red y unen redes entre sí. Usan la dirección del destino, junto con lo que
saben de la red, para decidir **por dónde enviar** cada mensaje.

Funciones que cumplen los dispositivos intermediarios:

1. **Regenerar y retransmitir** las señales de comunicación.
2. **Mantener información** sobre las rutas que existen en la red.
3. **Avisar** a otros dispositivos de errores y fallas de comunicación.
4. **Elegir caminos alternativos** cuando un enlace falla.
5. **Clasificar y priorizar** mensajes según su tipo (por ejemplo, la voz antes que una descarga).
6. **Permitir o bloquear** tráfico según la configuración de seguridad.

## 1.2.5 Medios de red

El medio es el canal por el que viaja el mensaje. Hay tres tipos, y cada uno codifica los datos de forma distinta:

| Medio | Cómo viajan los datos | Dónde se usa |
|---|---|---|
| Hilos de metal (cobre) | Impulsos eléctricos | Cableado de oficinas y casas (UTP) |
| Fibra óptica | Pulsos de luz | Enlaces largos y de alta velocidad, entre edificios y ciudades |
| Inalámbrico | Ondas electromagnéticas | Wi-Fi, redes celulares, satélite |

Para elegir el medio, se tienen en cuenta cuatro criterios:

1. **Distancia máxima** que puede cubrir con éxito.
2. **Entorno** donde se instalará (interferencias, humedad, exterior).
3. **Cantidad de datos y velocidad** que debe transmitir.
4. **Costo** del medio y de su instalación.
