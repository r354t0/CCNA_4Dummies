## 3.8.1 Lo que aprendiste

| Tema | Lo esencial |
|---|---|
| 3.1 Las reglas | Origen, canal y destino. Codificación, formato y encapsulación, tamaño, sincronización (flujo, tiempo de espera, acceso) y entrega (unicast, multicast, broadcast) |
| 3.2 Protocolos | Tipos: comunicación, seguridad, enrutamiento, detección de servicios. Funciones: direccionamiento, confiabilidad, flujo, secuencia, errores, interfaz de aplicación |
| 3.3 Suites | TCP/IP es la suite abierta de Internet. Protocolos por capa: DNS, DHCP, HTTP, SMTP; TCP y UDP; IP, ICMP, OSPF; ARP, Ethernet, WLAN |
| 3.4 Estándares | ISOC, IAB, IETF (RFC), IRTF, ICANN e IANA para Internet; IEEE, EIA, TIA y UIT-T para electrónica y comunicaciones |
| 3.5 Modelos | OSI (7 capas, referencia) y TCP/IP (4 capas, protocolo). Cada capa tiene funciones y PDU propias |
| 3.6 Encapsulamiento | Segmentación, multiplexación y secuencia. Datos, segmento, paquete, trama y bits |
| 3.7 Acceso a los datos | IP de extremo a extremo, MAC de salto a salto. A otra red, la trama va al gateway |
