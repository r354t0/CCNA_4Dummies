## 2.9.1 La configuración completa, de un vistazo

```text
enable
configure terminal
 hostname S1
 no ip domain-lookup
 enable secret Cl4ss!2026
 service password-encryption
 banner motd #Acceso solo para personal autorizado#
 line console 0
  password C0ns0la!26
  login
 line vty 0 15
  password Rem0t0!26
  login
  transport input telnet ssh
 interface vlan 1
  ip address 192.168.1.2 255.255.255.0
  no shutdown
 ip default-gateway 192.168.1.1
 end
copy running-config startup-config
```

`no ip domain-lookup` evita que IOS intente resolver por DNS cada comando mal escrito (te ahorra esperas de varios
segundos en el laboratorio).

## 2.9.2 Lo que aprendiste

| Tema | Lo esencial |
|---|---|
| 2.1 Acceso | Shell, kernel y hardware. Consola (fuera de banda), SSH y Telnet (en banda). Emuladores de terminal |
| 2.2 Navegación | `>` EXEC de usuario, `#` EXEC privilegiado, `(config)#` global y submodos. `enable`, `configure terminal`, `exit`, `end` |
| 2.3 Comandos | Comando, palabras clave y argumentos. Ayuda con `?`. Mensajes de error. Abreviaturas y teclas rápidas |
| 2.4 Configuración básica | `hostname`, `enable secret`, contraseñas de consola y VTY con `login`, `service password-encryption`, `banner motd` |
| 2.5 Guardar | running-config en RAM, startup-config en NVRAM. `copy run start`, `reload`, `erase startup-config` |
| 2.6 Puertos y direcciones | IP, máscara y gateway. Puertos físicos sin IP; la SVI para administrar |
| 2.7 Direcciones IP | Estática o DHCP en hosts. `interface vlan 1`, `ip address`, `no shutdown`, `ip default-gateway` |
| 2.8 Verificar | `show ip interface brief`, `ipconfig` y `ping` |
