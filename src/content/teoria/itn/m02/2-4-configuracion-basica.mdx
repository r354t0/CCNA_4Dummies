## 2.4.1 Nombres de los dispositivos

El primer comando que se configura es el **nombre de host**. Todos los switches de fábrica se llaman `Switch`; con
diez switches iguales no sabrías en cuál estás conectado.

```text
Switch(config)# hostname Sw-Piso2
Sw-Piso2(config)#
```

El prompt cambia en cuanto pulsas Enter. Las reglas para un nombre válido:

| Regla | Válido | No válido |
|---|---|---|
| Empieza con una letra | `Sw-Piso2` | `2-Sw` |
| No tiene espacios | `Sw-Piso2` | `Sw Piso2` |
| Termina con letra o dígito | `Sw-Piso2` | `Sw-Piso-` |
| Solo letras, dígitos y guiones | `Sw-Piso2` | `Sw_Piso!2` |
| Menos de 64 caracteres | `Sw-Piso2` | Un nombre de 70 letras |

Para volver al nombre de fábrica: `no hostname`.

## 2.4.2 Pautas para las contraseñas

- Usa **más de ocho caracteres**.
- Combina **mayúsculas, minúsculas, números y símbolos**.
- No repitas la misma contraseña en todos los equipos.
- Evita palabras del diccionario y datos personales.

<aside class="dato">

En los laboratorios de NetAcad se usan contraseñas simples como `cisco` o `class` para ir rápido. En una red real
serían inaceptables.

</aside>

## 2.4.3 Configuración de contraseñas

Hay tres puntos de acceso que proteger:

| Qué se protege | Comandos |
|---|---|
| Acceso al modo EXEC privilegiado | `enable secret` *contraseña* |
| Consola (acceso al modo EXEC de usuario por cable) | `line console 0`, `password` *contraseña*, `login` |
| Acceso remoto por Telnet o SSH (líneas VTY) | `line vty 0 15`, `password` *contraseña*, `login` |

`transport input` define qué protocolos aceptan las líneas VTY: `ssh`, `telnet`, ambos, `all` o `none`. En equipos
recientes el valor por defecto es `none`, así que hay que indicarlo.

<aside class="ojo">

Si existe `enable password` **y** `enable secret`, IOS usa solo `enable secret`. No configures los dos.

</aside>

## 2.4.4 Cifrado de las contraseñas

En la configuración, las contraseñas de consola y VTY aparecen en **texto plano**:

```text
line con 0
 password C0ns0la!26
 login
```

Después de `service password-encryption`:

```text
line con 0
 password 7 106D591716471E0A4D567C
 login
```

El `7` indica el tipo de cifrado. Es **débil** (se revierte en segundos): solo evita que alguien lea las contraseñas
por encima de tu hombro. Por eso `enable secret` usa un hash más fuerte desde el principio.

## 2.4.5 Mensajes de aviso (banner)

Un **banner MOTD** se muestra a quien intenta conectarse. Advierte que solo el personal autorizado puede entrar, y
tiene valor legal: un intruso no puede decir que no sabía que estaba prohibido.

```text
Sw-Piso2(config)# banner motd #Acceso solo para personal autorizado#
```

El primer carácter después de `motd` es el **delimitador**: el mensaje termina cuando IOS lo vuelve a encontrar. Elige
uno que no aparezca en el texto (`#`, `$`, `%`).

<aside class="ojo">

Nunca uses la palabra «bienvenido» en un banner: parece una invitación a entrar.

</aside>
