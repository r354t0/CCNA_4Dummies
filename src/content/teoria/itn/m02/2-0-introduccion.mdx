En el módulo 1 viste qué piezas forman una red. Ahora vas a **configurarlas**: entrar a un switch Cisco, darle un
nombre, protegerlo con contraseñas, asignarle una dirección IP y comprobar que todo se comunica.

## 2.0.1 ¿Por qué estudiar este módulo?

Porque todo lo que configures en el resto del CCNA empieza aquí. Las simulaciones del examen asumen que te mueves con
soltura por la línea de comandos de IOS, que conoces sus modos y que no dudas con los comandos básicos.

## 2.0.2 Qué vas a aprender

| Tema | Objetivo |
|---|---|
| 2.1 Acceso a Cisco IOS | Explicar cómo se accede a un dispositivo con Cisco IOS para configurarlo |
| 2.2 Navegación del IOS | Moverse entre los modos de comando de IOS |
| 2.3 Estructura de comandos | Describir la estructura de los comandos de IOS y usar la ayuda |
| 2.4 Configuración básica de dispositivos | Configurar nombre, contraseñas y banner de un dispositivo IOS |
| 2.5 Guardar la configuración | Usar comandos de IOS para guardar la configuración en ejecución |
| 2.6 Puertos y direcciones | Explicar cómo se comunican los dispositivos a través de los medios de red |
| 2.7 Configurar direcciones IP | Configurar un dispositivo host con una dirección IP |
| 2.8 Verificar la conectividad | Verificar la conectividad entre dos dispositivos finales |

<aside class="clave">

Este módulo tiene mucha práctica. Lee cada tema y después ve a **Práctica › Consola IOS**: es una consola de switch en
el navegador donde puedes repetir cada comando sin miedo a romper nada.

</aside>
