## 2.3.2 Convenciones de sintaxis

La documentación de Cisco usa estas convenciones para describir los comandos:

| Convención | Significado |
|---|---|
| **Negrita** | Comandos y palabras clave que se escriben tal cual |
| *Cursiva* | Argumentos: valores que tú defines |
| `[x]` | Elemento opcional |
| `{x}` | Elemento obligatorio |
| `[x {y \| z}]` | Opción obligatoria (y o z) dentro de un elemento opcional |

Por ejemplo, **ping** *ip-address* significa: escribe `ping` y después la dirección que quieras.

## 2.3.3 Funciones de ayuda

IOS tiene dos tipos de ayuda:

- **Ayuda contextual (`?`)**: muestra qué comandos o parámetros son válidos en ese punto.
  - `?` solo: lista todos los comandos del modo actual.
  - `sh?`: lista los comandos que empiezan con «sh».
  - `show ?`: lista lo que puede ir después de `show`.
- **Verificación de sintaxis**: IOS revisa cada comando al pulsar Enter y avisa si algo está mal.

| Mensaje de error | Qué significa | Cómo se corrige |
|---|---|---|
| `% Ambiguous command: "show con"` | Lo que escribiste coincide con más de un comando | Escribe más letras hasta que sea único |
| `% Incomplete command.` | Faltan palabras clave o argumentos | Usa `?` después del último elemento para ver qué falta |
| `% Invalid input detected at '^' marker.` | Hay un error en la posición que señala el `^` | Corrige la palabra marcada |

```text
Switch# clock set 19:50:00
% Incomplete command.
Switch# clock set 19:50:00 ?
  <1-31>  Day of the month
  MONTH   Month of the year
Switch# c
% Ambiguous command: "c"
Switch# conigure terminal
         ^
% Invalid input detected at '^' marker.
```

## 2.3.5 Teclas de acceso rápido y abreviaturas

Cualquier comando o palabra clave se puede **abreviar** con las letras mínimas que la identifican sin ambigüedad:
`conf t` es `configure terminal` y `sh ip int br` es `show ip interface brief`. Pero `con` no sirve, porque también
empiezan así `connect` y otros comandos.

| Tecla | Acción |
|---|---|
| Enter | Muestra la línea siguiente |
| Barra espaciadora | Muestra la pantalla siguiente |
| Cualquier otra tecla | Termina la salida y vuelve al prompt |
