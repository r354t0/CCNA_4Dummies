## 1.6.1 Router y switch, lado a lado

<div class="duo">

<div>

#### Switch de capa 2

```text
interface vlan 99
 ip address 172.17.99.11 255.255.255.0
 no shutdown
ip default-gateway 172.17.99.1
!
interface fa0/1
 duplex full
 speed 100
```

</div>

<div>

#### Router

```text
ipv6 unicast-routing
interface g0/0/0
 description LAN de PC1
 ip address 192.168.10.1 255.255.255.0
 ipv6 address 2001:db8:acad:10::1/64
 no shutdown
interface loopback 0
 ip address 10.0.0.1 255.255.255.0
```

</div>

</div>

Y en los dos, SSH:

```text
hostname R1
ip domain-name ccna4dummies.lab
crypto key generate rsa general-keys modulus 1024
username admin secret Adm1n!2026
ip ssh version 2
line vty 0 4
 transport input ssh
 login local
```

## 1.6.2 Lo que aprendiste

| Tema | Lo esencial |
|---|---|
| 1.1 Configuración inicial | POST, boot loader, IOS. `boot system`. LED y botón Mode. SVI con `ip default-gateway` |
| 1.2 Puertos | Dúplex completo y semidúplex. `duplex`, `speed`, `mdix auto`. `show interfaces`: CRC, runts, giants, colisiones tardías |
| 1.3 Acceso remoto seguro | Telnet en texto plano; SSH cifra. Dominio, claves RSA, usuario local, `login local`, `transport input ssh`, `ip ssh version 2` |
| 1.4 Router | Configuración básica, `ipv6 unicast-routing`, interfaces en doble pila, `no shutdown`, loopback |
| 1.5 Verificación | `show ip interface brief`, `show ip route` (rutas C y L), `show ipv6 interface`, filtros `\|`, historial |
