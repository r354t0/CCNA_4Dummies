## 1.4.1 Parámetros básicos del router

La configuración básica de un router es la misma que ya conoces del switch:

```text
Router# configure terminal
Router(config)# hostname R1
R1(config)# enable secret Cl4ss!2026
R1(config)# line console 0
R1(config-line)# password C0ns0la!26
R1(config-line)# login
R1(config-line)# line vty 0 4
R1(config-line)# password Rem0t0!26
R1(config-line)# login
R1(config-line)# transport input ssh telnet
R1(config-line)# exit
R1(config)# service password-encryption
R1(config)# banner motd #Acceso solo para personal autorizado#
R1(config)# end
R1# copy running-config startup-config
```

Un detalle: los routers ISR suelen tener **cinco** líneas VTY (0 a 4), no dieciséis como el switch.

## 1.4.2 Para IPv6, un comando más

Un router reenvía IPv4 desde el primer momento. Para que reenvíe **IPv6** hay que activarlo:

```text
R1(config)# ipv6 unicast-routing
```

Sin este comando el router puede tener direcciones IPv6 en sus interfaces, pero no enruta paquetes IPv6 ni envía
mensajes de anuncio de router (RA), así que los hosts no pueden configurarse con SLAAC.

<aside class="examen">

La diferencia clave con el switch: en un **router** cada interfaz física es de capa 3 y lleva su propia IP, y **todas
vienen en shutdown**. En un switch de capa 2 los puertos vienen encendidos y la IP va en la SVI.

</aside>

## 1.4.5 Interfaces loopback

Una **loopback** es una interfaz lógica, interna del router. No depende de ningún cable, así que **siempre está up**
mientras el router funcione. Se usa para pruebas, como identificador del router (por ejemplo, en OSPF) y para
administración.

```text
R1(config)# interface loopback 0
R1(config-if)# ip address 10.0.0.1 255.255.255.0
R1(config-if)# exit
%LINEPROTO-5-UPDOWN: Line protocol on Interface Loopback0, changed state to up
```

No necesita `no shutdown`. Puedes crear varias, cada una con un número distinto y en una red que no se solape con las
demás interfaces.
