## 3.6.1 La configuración completa de un switch

```text
vlan 10
 name docentes
vlan 20
 name alumnos
vlan 99
 name nativa
!
interface range fa0/1 - 12
 switchport mode access
 switchport access vlan 10
!
interface range fa0/13 - 24
 switchport mode access
 switchport access vlan 20
!
interface gi0/1
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99
 switchport nonegotiate
```

## 3.6.2 Lo que aprendiste

| Tema | Lo esencial |
|---|---|
| 3.1 Descripción de las VLAN | Cada VLAN es un dominio de difusión y una subred. Tipos: predeterminada, datos, nativa, administración, voz |
| 3.2 Multiswitch | Troncales. Etiqueta 802.1Q de 4 bytes con VID de 12 bits. La VLAN nativa va sin etiqueta y debe coincidir. VLAN de voz y CDP |
| 3.3 Configuración de VLAN | Rangos normal y extendido, `vlan.dat`. `vlan`, `name`, `switchport mode access`, `switchport access vlan`, `switchport voice vlan`. `show vlan brief`. Puertos inactivos al borrar una VLAN |
| 3.4 Troncales | `switchport mode trunk`, `native vlan`, `allowed vlan` (y `add`/`remove`). `show interfaces trunk` |
| 3.5 DTP | Modos access, dynamic auto, dynamic desirable, trunk. `nonegotiate`. auto + auto = acceso |
