## 4.5.1 Las dos configuraciones, lado a lado

<div class="duo">

<div>

#### Router-on-a-stick

```text
! Switch
interface gi0/1
 switchport mode trunk
! Router
interface g0/0/1.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface g0/0/1.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
interface g0/0/1
 no shutdown
```

</div>

<div>

#### Switch de capa 3

```text
ip routing
interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown
interface vlan 20
 ip address 192.168.20.1 255.255.255.0
 no shutdown
interface g1/0/1
 no switchport
 ip address 10.10.10.2 255.255.255.0
```

</div>

</div>
