## Objetivos

- Configurar router-on-a-stick con una subinterfaz por VLAN.
- Configurar el enlace del switch hacia el router como trunk.
- Reemplazar el router por un switch de capa 3 con SVIs e `ip routing`.
- Verificar con `show ip route` y `tracert` cuál equipo está enrutando.

## Punto de partida

Este laboratorio continúa el anterior: VLANs 10, 20, 99 y 999 en ambos switches, puertos de acceso asignados y trunk
S1–S2 con nativa 999. Si no lo tienes guardado, pega esta configuración en cada switch.

<details class="solucion">
<summary>Ver la configuración de partida de S1 (en S2, cambia el nombre y la IP a .12)</summary>

```text
enable
configure terminal
hostname S1
no ip domain-lookup
vlan 10
 name Ventas
vlan 20
 name Bodega
vlan 99
 name Gestion
vlan 999
 name Nativa
 exit
interface fastethernet0/1
 switchport mode access
 switchport access vlan 10
interface fastethernet0/2
 switchport mode access
 switchport access vlan 20
interface gigabitethernet0/1
 switchport mode trunk
 switchport trunk native vlan 999
 switchport trunk allowed vlan 10,20,99,999
 switchport nonegotiate
interface vlan 99
 ip address 192.168.99.11 255.255.255.0
 no shutdown
 exit
ip default-gateway 192.168.99.1
end
```

</details>

## Parte A1: El trunk hacia el router

En S1, configura G0/2 como trunk con la misma VLAN nativa y las mismas VLANs permitidas que el trunk entre switches.

## Parte A2: Subinterfaces en R1

1. Nombra el router **R1** y enciende la interfaz física G0/0/1 (sin dirección IP).
2. Crea las subinterfaces .10, .20 y .99, cada una con su encapsulación 802.1Q y la IP de la tabla.
3. La VLAN 999 no necesita subinterfaz: no tiene equipos ni dirección IP.

1. Desde PC1 haz ping a PC4: ahora debe responder.
2. Desde PC3 ejecuta `tracert 192.168.20.12`. El primer salto debe ser **192.168.10.1**: el tráfico de PC3 cruza el
   trunk S2–S1, sube por el trunk hacia R1, vuelve a bajar y llega a PC2.
3. Desde S2 haz ping a 192.168.10.11: los switches ya tienen gateway.

## Parte B: Reemplazar el router por un switch de capa 3

Ahora vas a sacar a R1 y poner en su lugar un switch **3650**, llamado **DS1**.

1. Agrega un 3650-24PS. En Packet Tracer viene sin fuente de poder: en la pestaña **Physical**, arrastra el módulo
   **AC-POWER-SUPPLY** a la ranura vacía para encenderlo.
2. Desconecta R1 y conecta DS1 G1/0/1 a S1 G0/2.
3. En DS1: nombre, las cuatro VLANs con sus nombres, y G1/0/1 como trunk (primero fija la encapsulación `dot1q`)
   con nativa 999 y las mismas VLANs permitidas.
4. Crea las SVI 10, 20 y 99 con las mismas IP que tenían las subinterfaces de R1.
5. Habilita el enrutamiento IP.

Verifica:

```text
DS1# show ip route
...
C    192.168.10.0/24 is directly connected, Vlan10
C    192.168.20.0/24 is directly connected, Vlan20
C    192.168.99.0/24 is directly connected, Vlan99
```

Repite los pings y el `tracert` de la Parte A. Los resultados para el usuario son idénticos: cambió quién enruta, no
las direcciones.

## Solución

<details class="solucion">
<summary>Ver la configuración de la Parte A</summary>

En S1:

```text
interface gigabitethernet0/2
 switchport mode trunk
 switchport trunk native vlan 999
 switchport trunk allowed vlan 10,20,99,999
 switchport nonegotiate
```

En R1:

```text
enable
configure terminal
hostname R1
no ip domain-lookup
interface gigabitethernet0/0/1
 no shutdown
interface gigabitethernet0/0/1.10
 description Gateway Ventas
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
interface gigabitethernet0/0/1.20
 description Gateway Bodega
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
interface gigabitethernet0/0/1.99
 description Gestion
 encapsulation dot1Q 99
 ip address 192.168.99.1 255.255.255.0
 end
copy running-config startup-config
```

</details>

<details class="solucion">
<summary>Ver la configuración de la Parte B</summary>

```text
enable
configure terminal
hostname DS1
no ip domain-lookup
vlan 10
 name Ventas
vlan 20
 name Bodega
vlan 99
 name Gestion
vlan 999
 name Nativa
 exit
interface gigabitethernet1/0/1
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk native vlan 999
 switchport trunk allowed vlan 10,20,99,999
 switchport nonegotiate
interface vlan 10
 ip address 192.168.10.1 255.255.255.0
 no shutdown
interface vlan 20
 ip address 192.168.20.1 255.255.255.0
 no shutdown
interface vlan 99
 ip address 192.168.99.1 255.255.255.0
 no shutdown
 exit
ip routing
end
copy running-config startup-config
```

</details>
